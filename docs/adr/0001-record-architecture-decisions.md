# 0001. Record architecture decisions

- Status: Accepted
- Date: 2026-10-06

## Context

The project is built phase by phase. Each phase is approved individually, and open questions are answered one at a
time. Decisions must stay traceable so later phases don't rely on assumptions.

## Decision

Every answered open question from `IMPLEMENTATION_PLAN.md` §12 is recorded as an ADR in this folder, numbered
sequentially. A decision that is later changed gets a new ADR that supersedes the old one, rather than an edit to it.

## Consequences

The plan's §12.1 table stays a summary. The ADRs hold the reasoning.
